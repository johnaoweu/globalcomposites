# Global Composite website concept

A responsive, single-page redesign concept for Global Composite. The direction pairs precise industrial typography, an engineered dark-and-lime palette, layered material-inspired visuals, and a focused conversion path.

## Preview

Run any static server from the project root:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Design walkthrough

- **Hero:** establishes a confident technical position and immediately offers a project enquiry.
- **Company story:** turns the value proposition into three clear, scannable benefits.
- **Capabilities:** presents design, prototyping, and manufacture as one connected workflow.
- **Industries:** provides visual routes for aerospace, mobility, and industrial customers.
- **Approach:** makes the engagement process predictable in four simple steps.
- **Contact:** closes with a high-contrast, low-friction call to action.

All artwork is CSS-based, so the concept has no stock-image licensing dependency.
